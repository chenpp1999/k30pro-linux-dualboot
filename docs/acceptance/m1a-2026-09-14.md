## 关键发现（均为实测根因）

1. **weston 启动即 abort**：msm 驱动 IN_FORMATS 含重复条目，触发
   `weston_drm_format_array_add_format`（drm-formats.c:131）断言；
   以二进制补丁（`bl __assert_fail` → NOP）修复，行为与 D80 基线所用
   pmOS 补丁版一致。
2. **`no input devices found`**：Alpine 基座无 udevd，libinput 的 udev
   后端枚举不到触摸/键盘；安装并启动 eudev 解决。
3. **截图授权**：`weston-screenshooter` 仅在 `weston --debug` 下被授权
   （上游安全策略），headless 验证依赖此。
4. **无头交互**：`/dev/uinput` 注入触摸（`tools/m1/utouch.c`），实现
   "点击输入框 → OSK 弹出 → 按键 → 字符插入"全链路自动验证。

## 遗留（转 M1b）

- 持久化安装（super 空闲空间 + recovery 引导）未做；
- weston 光标主题缺失（外观点缀）；
- libweston 二进制补丁建议跟随上游修复；
- OSK 依赖 text-input 客户端（终端不触发），与 D80 基线一致。
