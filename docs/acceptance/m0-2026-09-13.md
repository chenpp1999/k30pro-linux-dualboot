## 前置条件

- bootloader 已解锁：`fastboot getvar unlocked` → `yes`；
- 产物 sha256 与上表一致；initramfs 内 `/init` 为 LF（issue #3 修复后断言：
  `CRLF shebang: 0, LF shebang: 1`）；
- Windows 宿主 fastboot 驱动可用（驱动 GUID 注意事项见 runbook §3）。

## 执行步骤

1. `fastboot boot boot-m0.img`（发送 46,188 KB，总计 1.6s）；
2. 内核启动（`Freeing unused kernel memory` @ ~18.4s），initramfs `init` 执行；
3. 宿主出现 `UsbNcm Host Device`（USB `0525:a4a2`，序列 `LMI-M0-0001`），
   配置 `172.16.42.2/24`；
4. `ping 172.16.42.1`；
5. `ssh root@172.16.42.1`（密码 `<your-password>`）收集证据；
6. `reboot -f` 重启，回归 Android。

## 遗留问题（转 M1 / 后续）

1. **显示黑屏**：`panel_node not found` / `no port node found in
   /sys/qcom,dsi-display-primary`，疑似 DTB 显示管线缺 overlay（`lmi-sm8250-overlay.dtbo`
   未参与布局）；列入 M1 显示接管。
2. 触摸事件在面板未上电时不上报；M1 显示接管后复测 A4。
3. lmi 上普通 `reboot` 不生效，已验证 `reboot -f` 与长按电源；runbook 已更新。
4. 本轮为首个方式 A 成功启动；此前失败链条（方式 B 失败 → BCB 残留 → fastboot
   循环）见 issue #1，根因（init CRLF）见 issue #3。
