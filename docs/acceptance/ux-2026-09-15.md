## 2. 关键实测输出（摘要）

- `/etc/m1b-overlay-version` = `m1b-ux-v5`；manifest = 32 文件/19 目录（去 CRLF 后）。
- 引导账本：`boot=21 … bcb=boot-recovery … overlay=applied`（v9b 首启）。
- 键盘/终端/词典 sha256 与仓库一致：`a0dd6d82…`（keyboard）、`830ccf53…`（terminal）、
  `0585846b…`（pinyin.dict）。
- 息屏/唤醒：`brightness 0 → 944`；`lmi-keys: screen off (idle)` / `screen on`。
- 快捷键：终端出现 `^C` 且提示符恢复（Ctrl latch + `c`）。

## 3. 未覆盖 / 已知限制

- 方式 A（`fastboot boot` RAM 引导）未对 v9/v9b 执行（设备侧构建无 fastboot）；
  内核/DTB/DTBO/cmdline 与已验收 v8 逐字节一致，差异仅在 ramdisk 内容。
- 候选条固定 8 项/页；无模糊音、无用户词库、无长按备选、无滑动（README 的 Known gaps）。
- 编辑器中文显示走 Pango（无需配置）；终端以外的 cairo toy-API 客户端需自行指定 CJK 字体。
- 蓝牙/音频/传感器未涉及（非本次范围）。

## 4. 回滚

- overlay：随下一次镜像重建下发新版本覆盖；或从 `rootfs-live*.img` 恢复。
- recovery 镜像：`dd` 回 v8（`/root/m1b-rebuild/source.img`，`4b2ce34b…`）。
- TWRP：`tools/m1/recovery-swap.sh restore-twrp`（已演练）。
